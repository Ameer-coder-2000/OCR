Vercel-ready static build

OCR that works on Vercel without PHP.

Upload an image, send it straight to OCR.space from the browser, and copy or download the extracted text immediately. This version replaces the old PHP redirect flow so the site opens cleanly as a static deployment.

No PHP runtime Browser upload Mobile friendly

How it works

  • 1
    Choose an image from your device or drag it into the upload box.
  • 2
    The browser posts it to OCR.space using the public test key.
  • 3
    Copy the result, or download it as a plain text file.
Important

Vercel does not execute PHP files, so the old `index.php` redirect was the reason your site downloaded a file. This page is built to serve directly as `index.html`.

Upload image

PNG, JPG, GIF, and BMP are supported. Large files may take longer to process.
